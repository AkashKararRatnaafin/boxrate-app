# BoxRate

A box price calculator app, built with React + Vite.

## Setup (first time only)

1. Install [Node.js](https://nodejs.org) (LTS version) if you don't already have it.
2. Open a terminal in this folder and run:
   ```
   npm install
   ```

## Run it locally (to preview on your computer)

```
npm run dev
```
Then open the link it shows (usually http://localhost:5173) in your browser.

## Build for deployment

```
npm run build
```
This creates a `dist/` folder with the finished app, ready to upload to a host like GitHub Pages, Vercel, or Netlify.

## What's in here

- `src/App.jsx` — the verify-grid screen (the box list + pricing)
- More screens (dashboard, vendor list, photo capture) will be added here as we build them.
